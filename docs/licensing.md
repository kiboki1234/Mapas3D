# Licencias y procedencia

## Implementación actual

Cada trabajo registra proveedor, dataset, URL, licencia, fecha, recuento, caché y advertencias. Los edificios conservan identificadores originales y fuente de cada atributo. El GLB contiene `extras` por nodo; `metadata.json` conserva el historial completo.

| Fuente | Tratamiento actual |
|---|---|
| OpenStreetMap | ODbL-1.0, `© OpenStreetMap contributors` |
| Overture Buildings | ODbL-1.0, `© OpenStreetMap contributors, Overture Maps Foundation` |

Overture Buildings integra fuentes con atribuciones adicionales. El archivo `ATTRIBUTIONS.txt` acompaña cada modelo y enlaza los términos oficiales.

## Perfiles

- Comercial: solo adaptadores registrados como compatibles con uso comercial bajo sus condiciones.
- Investigación: reservado para conjuntos adicionales; no elimina ni elude restricciones.

Una fuente sin política registrada bloquea la generación. Una incompatibilidad no resuelta debe bloquear combinación/exportación, no esconderse como advertencia.

## Alcance legal

El GLB puede ser una obra producida o formar parte de una base derivada. La decisión depende del uso, distribución y relación con la base original. Esta documentación técnica preserva evidencia, pero no constituye asesoría jurídica.
